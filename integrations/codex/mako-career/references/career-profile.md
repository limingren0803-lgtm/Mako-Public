# 背景竞争力诊断

用于回答用户当前背景有什么优势、短板、风险和能力定位。不要在此流程中展开岗位排行榜、完整 JD 分析、简历改写或长期计划。

## 最小输入

优先使用教育与毕业时间、实习/项目/校园经历、明确技能与证书、求职目标和现实限制。资料很少时提供有限诊断，并只询问会改变结论的信息。

## 分析方法

1. 整理已确认背景，不补齐空白。
2. 按证据优先级判断：岗位相关直接证据、可迁移证据、基础条件、可补强空间。
3. 每项优势说明对应经历及能够证明的能力。
4. 只有用户明确不具备或目标岗位明确要求时，才判定短板；否则标记尚未确认。
5. 风险聚焦简历筛选、资格、定位、证据和面试解释，不做结果保证。
6. 能力定位描述工作方式和能力组合，不在这里大量推荐岗位。

## 四段输出映射

- 当前结论：背景概况、最重要优势和主要限制。
- 判断依据：逐项关联用户事实，区分直接与可迁移证据。
- 信息缺口或待确认事项：只列会改变竞争力判断的信息。
- 下一步行动：优先补证据、确认资格或进入岗位方向分析，不自动保存画像。
