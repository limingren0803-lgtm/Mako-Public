# Mako Career Prompt Pack 快速使用

这套 Prompt Pack 面向暂不支持直接安装 Agent Skill 的聊天产品和自定义智能体。它与可安装版使用同一套求职分析逻辑，但不会连接 Mako 平台，也不会由 Mako 替用户保存简历、求职意向或岗位状态。用户仍可使用所在平台真实提供的对话上下文或记忆能力。

## 选择适合当前平台的方式

| 当前环境 | 推荐方式 | 用户要做什么 |
| --- | --- | --- |
| 支持 Agent Skills | 安装完整 Skill | 安装 `integrations/codex/mako-career` |
| 支持自定义智能体或系统提示词 | 完整 Prompt | 复制 [FULL_PROMPT.md](FULL_PROMPT.md) 作为智能体设定 |
| 只有普通聊天 | 轻量 Prompt | 在新对话先粘贴 [LITE_PROMPT.md](LITE_PROMPT.md) |
| 对话长度有限或只分析一个问题 | 轻量 Prompt + 任务起始语 | 只提供当前任务所需材料 |

这套分层方式适用于 DeepSeek、豆包、千问、Kimi、腾讯元宝及其他聊天或智能体产品。具体产品是否支持自定义智能体、文件、搜索和记忆，以用户当前使用的版本为准；不能因为列在这里就理解为支持直接安装 Agent Skill。

## 使用完整 Prompt

### 平台支持自定义智能体或系统提示词

1. 打开 [FULL_PROMPT.md](FULL_PROMPT.md)，复制全文；
2. 粘贴到平台提供的系统提示词、自定义指令或智能体设定中；
3. 保存后，在该智能体中提供自己的材料和问题。

### 平台只有普通聊天但上下文充足

1. 新建一个专门用于求职分析的对话；
2. 先粘贴 [FULL_PROMPT.md](FULL_PROMPT.md) 全文；
3. 等智能体确认后，再发送材料和下面的任务起始语；
4. 后续尽量在同一对话继续，避免上下文被切断。

## 使用轻量 Prompt

普通聊天、移动端或上下文长度有限时，先粘贴 [LITE_PROMPT.md](LITE_PROMPT.md)，再发送一个任务起始语和必要材料。轻量版保留六类路由、事实边界、官方来源和用户确认规则，省略了更细的流程说明。

各平台的界面和能力会变化。能否上传 PDF/DOCX、能否联网、是否保留长期记忆，以用户当前使用的产品和账号为准。Prompt Pack 本身不会增加平台原本没有的附件、搜索或记忆能力。

## 六类任务起始语

### 1. 背景诊断

```text
请使用 Mako Career 的背景诊断流程。先根据我明确提供的经历判断优势、限制和证据缺口；信息不足时只问会改变结论的问题，不要推荐一长串岗位。
```

### 2. 岗位方向

```text
请使用 Mako Career 的岗位方向流程。根据我的真实经历和偏好，给出主线、辅助和探索方向，并说明每个方向的依据、缺口和补强成本，不使用匹配百分比。
```

### 3. JD 分析

```text
请使用 Mako Career 的 JD 分析流程。先拆解这份 JD 的职责、资格、核心能力和加分项，再逐项对应我的经历；把实际缺口、表达缺口和待确认信息分开。
```

### 4. 简历优化

```text
请使用 Mako Career 的简历优化流程。只在我提供的事实范围内修改，不新增数字、工具、职责或成果；说明改动依据，并把需要我确认的内容单独列出。
```

### 5. 面试准备

```text
请使用 Mako Career 的面试准备流程。结合 JD 和我的真实经历确定准备重点；缺少事实的 STAR 素材只给骨架，不替我编造完整故事。
```

### 6. 行动规划

```text
请使用 Mako Career 的行动规划流程。按截止风险、当前投递和面试、证据缺口安排未来一到两周；每项任务写清完成标准，不生成看似精确的长期日程。
```

## 分析当前招聘信息

如果问题涉及正在开放的岗位、校招窗口、留学生资格或企业政策，可以追加：

```text
这部分信息可能变化。若你具备联网或搜索能力，请只优先核验企业官方招聘网站或官方公告，标注来源和核验日期；若无法联网或无法可靠读取，请让我提供官方链接、完整 JD 或页面正文，不要用往年经验代替当前事实。
```

用户可以把企业官方招聘链接和岗位正文发给智能体。是否需要启用搜索插件、联网模式或网页工具，由当前平台决定；Mako Prompt Pack 不绑定某一个搜索服务。

## 材料建议

一次只提供完成当前任务需要的材料：

- 背景诊断：教育、经历、技能、目标和现实限制；
- 岗位方向：背景材料，加上城市、行业、工作方式与排斥项；
- JD 分析：完整 JD；需要个性化判断时再提供简历或经历；
- 简历优化：原始简历或具体经历，有目标岗位时一并提供 JD；
- 面试准备：JD、简历、面试轮次和时间；
- 行动规划：目标岗位、截止时间、当前进度和每周可投入时间。

真实材料中不需要的信息可以先删除或遮盖。平台如何保存聊天、附件和记忆，应以其隐私说明和用户设置为准。
