# Mako v1.9.0 发布说明

发布日期：2026-08-12

## 版本概览

Mako v1.9.0 扩展了官方招聘来源覆盖，并将职位导入、审核和用户可见的数据状态连接成完整流程。CareerProfile、Memory、六个 Career Skills 和现有聊天接口保持兼容。

## 企业覆盖与代表性案例

官方招聘来源目录由 15 家扩展至 23 家，新增 Microsoft、SAP、Siemens、P&G、Unilever、Deloitte、EY 和 HSBC，覆盖软件与云服务、企业软件、工业制造、消费品、专业服务和跨国金融服务。

目录覆盖与页面级接入分开推进。百度、SAP 和 Microsoft 分别作为国内互联网、企业软件和跨国科技企业的代表性案例：

- 百度适配器读取官网服务端渲染的公开职位列表，并按不完整快照处理单页数据；
- SAP 适配器读取中国职位列表公开呈现的职位链接、编号、标题、地点和分页信息；
- Microsoft 适配器读取大中华区公开页面呈现的职位卡片和官方详情链接，并按不完整快照处理精选结果。

其他企业保留经过核验的官方招聘入口，并可通过受控结构化导入补充职位。目录登记不等同于自动读取能力。

## 数据状态与批量流程

`GET /jobs/sources` 在保留原有来源明细和筛选参数的基础上，将企业汇总为“当前有已核验职位数据”和“当前仅提供官方招聘入口”两类。分组来自现有可用性信息，不包含内部来源健康、刷新策略或错误详情。

`POST /jobs/import/structured/batch` 支持为同一登记来源提交最多 50 条结构化职位，整批文本上限为 5 MB。来源、官方域名、字段限制、重复职位和内容隔离会在写入前完成检查，导入结果仍需审核后才能检索。

`POST /jobs/review/batch` 支持最多 50 项明确的批准或拒绝决定。完整批次会先检查重复项和待审核状态，再应用逐条决定。原有单条导入和审核接口继续可用。

## 安全与兼容性

- 聊天请求不会实时访问企业招聘网站；
- 外部职位内容在进入存储前执行来源、域名和内容安全检查；
- 不完整页面不会触发缺失职位的批量停用；
- Redis key、ChromaDB collection、CareerProfile Schema、Memory 行为和现有 API 路径保持不变。
