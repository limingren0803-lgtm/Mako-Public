# Mako v2.9.0 发布说明

## 版本概览

v2.9 重点修整简历、岗位信息和分析结果之间的连续性。用户可以明确决定本次分析使用材料库中的哪份简历、临时上传的简历，或不使用简历；连续求职任务会固定所选材料版本，避免后续阶段静默换用其他内容。

本版本同时扩展企业招聘来源目录，并加强独立分析的隐私边界、日期判断和结构化行动建议。Mako 仍以事实核对和用户确认为前提，不自动投递、填表、改变岗位阶段或写入未经确认的职业事实。

## 从一次分析继续到求职任务

- Career Workspace 可以围绕同一目标保留岗位、材料选择、当前阶段和用户明确保存的结果。
- 分析结果按结论、依据和下一步区分展示；用户可以在保留当前结果的同时继续追问。
- 行动建议先以待确认状态呈现，用户确认后才进入待办；分析完成不会自动改变岗位阶段。
- TXT、Markdown、文本型 PDF 和 DOCX 可用于本次分析，临时附件不会自动进入个人材料库。

## 轻量使用方式

可安装的 `mako-career` Skill 继续保持独立；不支持 Skill 安装的环境可使用同仓库中的 Mako Career Prompt Pack。两者都不连接 Mako Workspace 或读取平台个人材料。

## 简历与材料选用更明确

- 材料库支持指定当前简历；新增简历不会自动替换用户已经选定的版本。
- 独立分析可以选择材料库简历、仅用于本次请求的临时简历，或明确不使用简历。
- 连续求职任务记录简历和个人材料的当前版本；内容或状态变化后要求重新确认。
- 补充材料检索排除其他简历，结果区显示简历来源、解析状态、实际采用范围和截断情况。
- DOCX 文本框内容进入既有安全解析流程，不重复提取兼容内容。

## 招聘来源

- 企业招聘来源目录扩展至 109 家，并提供企业性质、行业和招聘渠道信息。
- 部分来源包含经过核验的招聘方向摘要，其余来源仅作为招聘入口，不表示具体岗位已经核验。
- 招聘信息来自公开网络及企业官方招聘平台；目录入口不代表具体岗位已经核验，实际岗位、条件和截止时间以企业官网为准。

## 分析连续性与行动建议

- 独立 Career 分析默认采用临时模式，不读取或写入 Redis 对话记忆，也不触发 CareerProfile 提取；页面明确提示本次结果未写入对话记忆。
- Career 请求使用服务端 Asia/Shanghai 当前日期判断明确的招聘截止时间；年份或日期不完整时继续保持待确认。
- JD 单点问题优先直接回答，不强制展开完整分析模板。
- 连续任务可以从同一次分析获得带原因、完成标准和来源的结构化候选行动；候选先保持 `suggested`，只有用户确认后才能进入 `todo`。
- 候选格式无效时保留分析正文，不创建行动，也不自动改变任务或岗位状态。

## 安全与兼容边界

- PDF 文本解析依赖更新至 `pypdf 6.21.4`；文件类型、解析接口、数据库 schema 和持久化挂载不变。
- 继续复用现有六个持久化挂载，不新增数据库或 Docker volume。
- `/mako/`、`/app/`、`/chat`、六项 Career Skill、CareerProfile、Redis key 和 ChromaDB collection 保持兼容。
- 临时附件不会自动保存到个人材料库，也不会写入官方职位库、Evidence Registry 或其他个人数据系统。

## 使用边界

- 企业招聘入口和岗位信息会变化；目录不替代企业官网的当前职位正文。
- 窄问题可以直接回答，但信息不足、材料冲突或日期不完整时仍会要求用户确认。
- Safari、Firefox、屏幕阅读器和实体触屏设备尚未完成专项验证。
- 扫描型 PDF 与图片 OCR 仍不在支持范围内。
