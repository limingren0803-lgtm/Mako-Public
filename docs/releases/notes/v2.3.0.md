# Mako v2.3.0 发布说明

发布日期：2026-08-29

## 版本概览

v2.3.0 新增 Career Workspace，让岗位分析结束后的目标、进度和下一步行动可以在本地继续管理。六项 Career Skill、CareerProfile、官方职位库、Evidence Registry、Redis 和 ChromaDB 保持原有数据边界。

## 求职行动总览

工作台新增三个进度页面：

- 求职总览：集中显示今天优先处理的行动、未来七天的截止事项和岗位阶段；
- 目标岗位：记录关注、投递、面试和结束等阶段，并保留岗位来源、报名截止时间和关联行动；
- 今日行动：按岗位和状态筛选任务，记录明确的完成标准，并支持编辑、完成、重新打开和删除。

用户可以从系统内已审核的官方职位建立岗位记录，也可以自行提供完整 JD。用户提供的链接只作为来源标注，系统不会自动访问。

## 本地数据与操作边界

Career Workspace 使用独立 SQLite 和 Docker volume，不反向写入 CareerProfile、Redis、ChromaDB、官方职位库或 Evidence Registry。

首次进入页面时，浏览器会自动建立 12 小时的本机会话。会话通过同源 HttpOnly Cookie 维持，页面不读取 Cookie 内容，也不保存长期访问令牌。

创建操作支持幂等键，更新和删除使用修订版本检查。数据已经发生变化时，页面会提示并重新读取最新状态。删除岗位与清空工作区前会先展示影响范围，工作区数据也可以导出为 JSON。

## 持久化与兼容性

备份工具纳入 Career Workspace 数据卷，同时继续识别旧的五卷备份。隔离恢复检查会验证工作区 SQLite 的完整性、外键和必要表结构。

本版本不修改既有 CareerProfile Schema、Redis key、ChromaDB collection、官方职位数据结构、Evidence Registry 或原有 API 路径。

## 当前边界

- Career Workspace 面向本机单用户使用，不提供线上账户或跨设备同步；
- Career Skill 的分析结果不会自动成为用户已确认的行动；
- 系统不会自动改变投递或面试阶段；
- PDF、DOCX 与个人知识库不属于本版本范围；
- ChromaDB 当前稳定版本仍有三项尚无修复版本的安全公告，公开 CI 仅对对应 CVE 使用精确临时例外，服务继续限制在本机网络边界。
