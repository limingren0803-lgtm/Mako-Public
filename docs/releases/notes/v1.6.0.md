# Mako v1.6.0 发布说明

发布日期：2026-08-11

## 版本概览

Mako v1.6.0 扩展了国内企业官方招聘来源覆盖，并增加受控的按需职位导入能力。该版本继续沿用 v1.5 的 JobPosting、版本管理和生命周期模型，不改变 CareerProfile、Memory 或六个 Career Skills 的行为。

## 官方来源目录

官方招聘来源由 5 家扩展到 15 家，覆盖互联网与数字平台、通信与智能硬件、汽车新能源和金融行业：

- 腾讯、字节跳动、美团、百度、阿里巴巴
- 华为、小米、OPPO、vivo、联想、中兴、大疆
- 比亚迪
- 中国工商银行、招商银行

每个来源记录官方招聘域名、入口、行业、招聘渠道、支持等级和核验日期。`GET /jobs/sources` 返回适合产品使用的只读目录字段，可按行业和支持等级筛选。

## 按需职位导入

管理接口支持两种导入方式：

- 将人工核验后的结构化 JD 与已登记官方页面关联；
- 当指定官方页面公开提供 Schema.org `JobPosting` 时，从该页面解析职位数据。

导入过程继续校验来源状态、HTTPS 官方域名、企业身份、字段边界和不受信任内容。相同职位内容沿用既有哈希规则去重，发生有效变化时保留历史版本。

## 使用边界

来源目录用于扩大可核验招聘入口的覆盖面，不等同于所有站点都支持自动抓取。v1.6.0 默认关闭自动获取，未验证的分页、动态接口和页面结构不会用于批量刷新，也不会因为空解析停用已有职位。

聊天请求仍然只读取本地已经验证的职位记录，不在回答过程中访问企业官网。投递前应通过返回的官方链接确认职位当前状态。

## 兼容性

以下内容保持不变：

- GeneralAgent、TechnicalAgent、CareerAgent 和六个 Career Skills；
- CareerProfile 字段、提取、合并和跨会话复用；
- Redis working-memory keys 和 ChromaDB collection 名称；
- 现有 Docker volume 名称及挂载位置；
- `/chat`、`/monitor`、`/debug/profile` 等既有 API 路径。

知识登记库通过增量迁移补充来源元数据，原有来源策略、自动化配置和职位记录不会被替换。
