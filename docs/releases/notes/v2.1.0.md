# Mako v2.1.0 发布说明

发布日期：2026-08-14

## 工作台任务闭环

v2.1.0 完善六项 Career Skill 的工作台体验。背景诊断、方向匹配、JD 分析、简历优化、面试准备和行动规划分别提供适合当前任务的输入提示、材料准备清单、使用步骤、结果说明和常见问题处理建议。

工作台继续使用选择功能、提供材料、确认输入和查看结果四步流程，不改变现有 Intent 路由和 Career Skill 业务规则。

## 两种职位材料入口

方向匹配支持使用系统内已审核职位，也支持用户自行提供完整 JD。

系统职位继续使用经过审核的本地职位版本和官方 JD 原文条目。自行提供的 JD 通过现有 `/chat` 流程完成本次分析，可选的 HTTPS 链接只作为来源标注，页面不会主动访问。用户提供的内容不会写入职位库、CareerProfile、Redis、ChromaDB 或长期证据库。

## 确认、结果与失败恢复

问题、经历、文件、JD、职位、岗位要求或分析范围发生变化时，页面会撤销此前的材料确认，避免以旧确认提交新内容。

分析完成后可以复制结果、下载 TXT 或重新开始。服务暂时不可用时，当前输入会保留，用户可以检查后直接重试。页面会区分等待材料、处理中、分析完成和需要处理等状态。

## 兼容性

- 六项 Career Skill、CareerProfile 和 Memory 行为保持不变；
- `/chat`、`/monitor` 等现有 API 路径保持不变；
- Redis key、ChromaDB collection、Docker volume 和职位库结构保持不变；
- PDF、DOCX、用户账户、跨设备恢复和长期用户证据管理仍未开放。
