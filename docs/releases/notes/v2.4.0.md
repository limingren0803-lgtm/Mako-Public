# Mako v2.4.0 发布说明

发布日期：2026-08-30

## 个人材料库

v2.4.0 为 Career Workspace 增加个人材料库。用户可以把简历、项目文档、课程材料和求职笔记保存在本地，在使用六个 Career Skill 时按需检索，并在分析结果中核对实际使用的材料与引用位置。

材料库支持 TXT、Markdown、带文本层的 PDF 和 DOCX。上传后先展示文件类型、篇幅、内容片段、定位信息和解析提示，确认后才保存规范化文本；原始二进制文件不会长期保留。

已保存的材料支持分类、筛选、详情、编辑、停用、重新启用、重建索引、导出和永久删除。写入操作提供幂等与 revision 冲突保护，避免重复创建或用旧页面状态覆盖新修改。

## 在 Career Skill 中使用材料

六个 Career Skill 提供三种选择：自动查找相关材料、只使用指定材料，以及本次不使用个人材料。系统只使用处于可用状态且达到相关性要求的片段；如果没有合适内容，会明确显示本次未引用个人材料。

分析结果会返回材料标题、分类和页码、章节或行号。普通 `/chat` 保持原有行为，不会自动检索个人材料；带材料的分析由本机会话保护的 `/v2/workspace/analyze` 发起。

## 数据边界

个人材料使用独立 SQLite 文件和独立 ChromaDB collection，并复用 Career Workspace 的本地持久化 volume。材料内容不会自动写入 CareerProfile、JobTrack、ActionItem、官方职位库、V2 Evidence Registry、Redis 或既有 ChromaDB collection。

材料中的指令、角色要求和工具请求只作为普通文本处理。检索片段不会自动变成已经确认的职业事实、岗位事实或求职阶段。

## 当前限制

- PDF 需要包含可提取的文本层，当前不提供 OCR。
- 不支持扫描 PDF、旧 DOC、DOCM、PPT、Excel、图片、音视频和压缩包。
- 当前仍是本地单用户工作区，不提供云端账户、跨设备同步或多人协作。
- 导出内容包含材料元数据、规范化文本和引用定位，不包含原始文件。
- `/v2/workspace/analyze` 会在用户主动提交时使用现有模型链路；材料预览、保存、索引和检索本身不调用模型。

## 公开验证

- 公开回归测试 141/141 通过。
- Python 编译、依赖审计、Docker Compose 配置和凭据模式扫描纳入公开 CI。
- 公开基础测试覆盖材料会话边界、解析定位、预览确认、导入、检索、来源展示和永久删除。
