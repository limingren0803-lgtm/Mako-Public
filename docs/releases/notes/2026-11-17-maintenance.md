# 工作台体验与稳定性更新

- 新用户可先做简短诊断，再选择是否保存为任务及保留简历；保存后可进入推荐工具，不自动发起下一次分析。
- 简历优化集中呈现修改稿，支持一键复制；修改说明分开展示，临时简历不混入旧任务对话。
- 修正工具弹窗进度条位置和横向溢出。
- 分段过多的文件上传返回明确提示，覆盖预览、保存和临时分析。
- 已拒绝职位重复导入不再产生无法审核的待审项，历史版本不覆盖当前职位信息。
- 持续异常合并为一个告警，恢复后解除，最多保留最近 1000 条。
- 明确常规 Agent 路由与显式并行接口的区别；启动配置和文档说明单进程、单实例边界。
- 增加虚构六阶段求职示例，展示材料引用、结果修正与行动确认。

更新不会自动改写已保存的历史分析。模型生成内容仍需对照原材料核对，尤其是个人分工、数字和成果。
