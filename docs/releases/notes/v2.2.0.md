# Mako v2.2.0 发布说明

发布日期：2026-08-15

## 版本概览

v2.2.0 集中改善模型使用效率、用量观测和服务访问稳定性。六个 Career Skill、CareerProfile、Memory 和职位匹配规则保持不变。

## 减少非必要模型调用

工作台已经明确选择 Career Skill 时，请求直接进入对应任务。没有提供选择的 API 客户端继续使用自动意图识别，现有调用方式保持兼容。

意图识别不再执行未被后续业务使用的实体提取。本地知识上下文和 `/search` 直接查询现有知识库，不额外调用模型改写或重排查询。

## 模型用量观测

模型调用统一记录到现有 Prometheus 指标。指标按调用用途、模型和执行结果统计请求次数，并读取供应商返回的输入、输出和缓存 token 数。

这些指标不包含提示词、简历内容、用户材料或用户标识。版本不内置模型价格，成本可以按实际供应商和合同价格在监控侧计算。

## 重试与入口保护

`/chat` 支持短期幂等请求。网络异常后使用同一幂等键重试相同内容时，服务可以复用五分钟内的执行结果；并发重复请求不会重复调用模型。同一键用于不同内容时返回冲突，失败请求仍可重新尝试。

Nginx 为 `/chat` 设置独立的请求节奏。超过限制时返回 `429`，工作台保留当前输入并提示稍后重试。本地职位检索、确定性匹配和页面访问不使用这条模型入口限流。

## 兼容性

本版本不修改 CareerProfile Schema、conservative merge、Redis key、ChromaDB collections、职位登记库、V2 证据库、Docker volume 或持久化路径。

五分钟幂等缓存面向当前单进程部署。扩展为多实例服务时，需要迁移到 Redis 或其他共享协调层。公网多用户部署仍需要可靠的身份、额度和 TLS 边界。
